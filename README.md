## components

STM32F722RET6 microcontroller 

-ICM-45686 IMU 

-BMP580 barometer 

-MicroSD card 

-Quad servo outputs 

-2-cell LiPo support with  BQ25883 charger

-USB-C connectivity 


## This project uses:

- [KiCad](https://www.kicad.org/)
